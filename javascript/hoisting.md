# 호이스팅(Hoisting)이란?

호이스팅은 "끌어올리다"라는 의미로, JavaScript에서 변수 및 함수 선언이 해당 스코프의 최상단으로 끌어올려지는 것처럼 동작하는 현상을 말한다.

## 변수 호이스팅

```javascript
console.log(x); // undefined

var x = 5;
```

JavaScript 엔진은 코드를 실행하기 전에 컴파일 과정을 거치며, 이 과정에서 `var x = 5`를 다음과 같이 두 단계로 나누어 해석한다.

- `var x;` (변수 선언)
- `x = 5;` (값 할당)

이때 변수 선언(`var x`)은 컴파일 단계에서 먼저 처리되어 스코프의 최상단으로 끌어올려지고, 값 할당(`x = 5`)은 실제 코드 실행 시점에 이루어진다.

따라서 `console.log(x)` 실행 시점에는 변수는 선언되어 있지만 값이 할당되지 않았기 때문에 `undefined`가 출력된다.

## 함수 호이스팅

```javascript
console.log(foo()); // "Hello, World!"

function foo() {
  return 'Hello, World!';
}
```

함수 선언문 또한 호이스팅이 발생한다. 이 경우에는 변수와 달리 함수 전체가 함께 호이스팅된다.

즉, 함수 선언이 코드 실행 전에 미리 메모리에 등록되기 때문에, 선언 이전에 호출하더라도 정상적으로 동작하여 `"Hello, World!"`를 출력한다.
